# Label schedule — rebuild harness

Generated by `tools/label_schedule.py`. Do not edit by hand.

Printed heat-shrink, **two labels per wire**. Each label names the
**far** end, because that is the question you have when you are
holding one end of a wire in a loom.

## ⚠️ Label and seal go on BEFORE the terminal is crimped

Heat shrink and the MP280 cavity seal both slide on from the wire
end. A crimped terminal will not pass either. The order is:

1. Slide on the printed heat-shrink label
2. Slide on the cavity seal
3. Strip
4. Crimp the terminal (conductor **and** seal wings)
5. Shrink the label

Getting this wrong means cutting the terminal off and starting
again, one wire at a time, and it is not recoverable any other way.
