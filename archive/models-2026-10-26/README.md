revision written as a DESIGN: blocker list, do-not-cut holds, issue
cross-references, the reasoning behind every rating and every rejected
alternative.

rewritten the same day to state the harness **as built** - what is on
the bike, in present tense, with only the reasoning a reader needs at
the bench. Nothing here is rendered and nothing here is authoritative;

Kept so the design history is readable without a git client, and so the
issues the build closed can point at the text they closed.
