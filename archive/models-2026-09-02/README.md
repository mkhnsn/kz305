# Model files as they stood before the 2 Sep 2026 notes cleanup

Verbatim copies. The live models under `models/` were rewritten on
2 Sep 2026 to state **what is** rather than how each claim got there:
present-tense fact, one evidence tag, no revision history.

These copies exist so the working-out is still readable at the bench
without a git client. Nothing here is rendered and nothing here is
authoritative — if this and `models/` disagree, `models/` is right.

The part of this history that still does work is not the narrative but
the failure record: which class of evidence produced which wrong claim.
That is distilled in `docs/overturned-claims.md`, which is live
documentation rather than an archive.
